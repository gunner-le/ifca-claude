Ghi trạng thái vào `docs/jira-context.md` (PHẦN B — ticket đang dở), cập nhật nếu đã có mục của ticket này:
- Màn hình / bảng / view / SP / file liên quan đã xác nhận
- Điều đã CHỐT (có dữ liệu chứng minh) và điều còn là GIẢ THUYẾT (ghi rõ)
- Các ID / chứng từ test, query quan trọng đã dùng
- File local đã sửa (tìm theo comment JiraID) và đã áp lên server/TFS chưa
- Dòng `TFS Live: so <file> ngày <yyyy-mm-dd>, mức A/B/C → kết quả` (hoặc "bỏ qua"/"chưa so") cho từng file/object đã hỏi
- Bước tiếp theo cụ thể
