- Chỉ ghi/update docs (dòng trong bảng này, và file chi tiết từng ticket) khi ticket có **kết quả cuối** — root cause đã confirm bằng data/code, fix đã áp dụng, hoặc ticket đã đóng. KHÔNG ghi lại mỗi lần trao đổi/mỗi vòng điều tra qua lại — tốn thời gian không cần thiết (Gunner yêu cầu 2026-09-09).
- Trong lúc đang điều tra dở dang (hypothesis chưa confirm, chờ user chạy query/test), cứ trao đổi, không ghi vào docs cho tới khi chốt được kết quả.
- Cột File chi tiết chỉ điền khi đã thực sự viết file — trước đó ghi "(chưa có)" hoặc "(chưa viết — sẽ viết khi có kết quả cuối)".
- Đoạn "Root Cause / Fix note (English, sẵn Jira)" chỉ được viết vào file chi tiết SAU KHI Gunner xác nhận root cause/fix đã test đúng — không viết khi mới là hypothesis/đề xuất, để tránh note sai phải sửa lại (Gunner yêu cầu 2026-09-13).
